# 1.2.0 漫画阅读器设计说明

日期：2026-10-12

## 目标

为花漫画增加独立的漫画阅读器。阅读器按故事楼层组织当前有效图片，支持楼层内翻页、跨故事楼层翻页、章节导航、重新生成和生成状态遮罩，同时兼容现有三种生图模式。

## 已确认范围

- 版本从 1.2.0 开始。
- ①“LLM 插图点生图”纳入阅读器；②、③也纳入。
- PageUp/PageDown 进入目标故事楼层的第一张图片。
- 没有阅读记录时，全局“阅读漫画”报错，不自动选择楼层。
- 非故事楼层在导航中跳过。
- 章节信息使用提示词模板产生的 `<chapter_title>` 和 `<chapter_summary>` 标签；缺失时显示“暂无”。
- 提示词由用户在现有模板中配置，代码不写死业务提示词。
- 不修改安装的 SillyTavern 源码和参考项目。

## 故事楼层判定

从当前聊天分支读取消息，保留正文非空、非用户、非系统、非注释、非独立旁白的角色回复。导航使用筛选后的故事楼层列表，但界面仍显示原消息索引。当前楼层不是故事楼层时，按导航方向寻找相邻故事楼层；不会把用户楼层、系统消息或旁白作为阅读目标。

## 数据与存储

新增阅读数据按用户当前聊天隔离，保存到 SillyTavern 当前用户 `files` 目录下的独立 JSON 文件。不得写死 `default-user`，由现有服务器存储接口确定实际用户路径。

JSON 只保存楼层级阅读元数据、章节标题、剧情简介、阅读进度及与现有图片记录的稳定引用；不保存图片 Base64。图片继续使用现有浏览器缓存和服务器图片引用。没有简介的历史数据显示“暂无”，不偷偷调用 LLM。

阅读进度至少包含聊天标识、故事楼层消息索引和当前图位索引。全局入口没有有效进度时直接报错。

## 图片适配

阅读器按正文图位顺序读取每个图位当前有效图片。每个图位只算一张漫画，历史重画版本不重复计数。①模式使用现有插图点数据和有效图片引用；②③使用现有图位、图片描述和章节标签。模式差异由适配层处理，阅读器只接收统一的页面列表。

## 阅读器界面与导航

新建独立阅读弹窗，不能把现有图片历史弹窗改造成阅读器。界面包含：居中标题、居中图片、剧情简介、当前页/总页数、左右箭头、右上角关闭按钮、底部紧凑楼层 toolbar 和“花漫画”按钮。

- 本楼层无漫画时显示空页面和“本楼层暂无漫画”，仍保留“花漫画”。
- 左右箭头及左右方向键翻页。
- 当前楼层第一张向左进入上一故事楼层最后一张；最后一张向右进入下一故事楼层第一张。
- 跨到没有漫画的故事楼层时停在该楼层空页面，不跳过该楼层。
- PageUp/PageDown 进入上一/下一故事楼层第一张。
- Esc 关闭阅读器。
- 输入框、确认弹窗或生成遮罩出现时暂停阅读快捷键。
- toolbar 只参考 ST-Chat-Jumper 的紧凑布局、楼层输入和导航交互；不重建酒馆聊天页面，不复制编辑、删除、收藏、换分支等功能。

## 章节与剧情简介

章节标题和简介是楼层级数据，不随图片翻页变化。整层生成完成后从模型输出中解析 `<chapter_title>` 和 `<chapter_summary>` 并保存；单张图片小铅笔改写或重画不更新整层简介。解析失败时保留已有值或显示“暂无”。①模式没有标签时同样显示“暂无”，不额外发起请求。

## 整层重新生成

楼层按钮和阅读器中的“花漫画”都执行同一整层重生成流程：

1. 检查当前楼层是否已有图位、图片或漫画描述。
2. 有内容时确认“本楼层已有漫画，是否重新生成？重新生成将清空本楼层现有图片及描述，并按本次要求重新生成。取消将保留现有内容。”
3. 用户取消确认或取消重点要求弹窗时，不删除旧内容。
4. 用户提交重点要求后，清空当前楼层图位、图片记录、描述及旧章节信息。
5. 清空失败则停止并提示；不能继续生图。
6. 清空成功后重新规划和生成，结果绑定原楼层。
7. 生成失败显示空页和错误；部分成功显示可用页面和错误；成功后阅读器刷新。
8. 不自动删除服务器上的旧图片文件。

现有自动配图、缺图补图和恢复任务行为保持不变；新入口不能直接复用“已有漫画则返回”的短路逻辑。

## 生成遮罩

生成任务开始时创建全页面遮罩，文案为“正在生成中，请勿关闭页面”，遮罩期间页面不可点击。楼层按钮、全局按钮和阅读器入口共用任务状态，避免重复创建遮罩。任务成功、失败或明确结束时移除遮罩；关闭阅读器不取消后台任务。

## 错误与兼容处理

- 没有阅读记录的全局入口直接报错。
- 非故事楼层不作为导航目标，按方向跳过。
- 没有漫画的故事楼层可打开空阅读页。
- 旧数据没有章节字段时不迁移图片、不补发模型请求。
- 当前楼层或聊天分支发生变化时，生成结果仍按任务绑定的聊天和消息索引写入，不能覆盖另一楼层。

## 验收标准

1. 三种模式都能打开阅读器，①模式不因缺少章节标签而报错。
2. 楼层内翻页、跨故事楼层翻页、PageUp/PageDown、Esc 和 toolbar 工作，不改变聊天页面。
3. 当前有效图位计数正确，历史重画版本不重复计数。
4. 标题、简介和阅读进度刷新后可恢复，并按聊天隔离。
5. 重生成两次取消都不删除；提交后先清空再生成；清空失败不生图。
6. 生成遮罩期间页面不可点击，任务结束后恢复。
7. 自动检查、模拟浏览器验证和真实酒馆验收分别记录，真实模型调用和发布不由本设计自动授权。
