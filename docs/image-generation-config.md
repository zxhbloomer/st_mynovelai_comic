# 花漫画：图片生成配置记录

每张新生成的图片保存生成时的预设名称、预设 ID、提示词前缀及生图参数。尺寸和种子取自实际发送的请求，包括悬浮窗尺寸覆盖和随机种子解析后的值。

点击小铅笔，在提示词上方查看生成配置。保存修改后的场景、角色提示词，再使用原有重绘按钮，会沿用这张图的参数和前缀。切换当前预设、修改原预设或改变悬浮窗尺寸，不会替换已有图片的记录。重绘沿用实际种子，因此随机种子预设生成的图片也使用原图种子。

记录覆盖聊天手动/自动配图、文本配图、失败记录和后台任务交付日志；画廊导出保留记录。配置存在本地图片缓存中，删除图片或清理缓存后不能从图片文件恢复这些记录。

不记录 API 密钥、地址或连接设置。重绘的地址、发送模式、超时和密钥读取当前配置。

小铅笔只显示生成配置及场景、角色 TAG 编辑框。原始描述框和“重新解析 TAG”按钮已移除，不从楼层正文推测单张图片的自然语言提示词。修改 TAG 后可保存或直接“保存并生图”，失败占位使用“保存并重试”。

旧图没有这些记录，编辑区会提示“旧图未记录生成配置，重绘使用当前预设和尺寸”，不会推测原配置。

## 验证

- `node --test modules/draw/providers/novelai/tests/novel-generation-snapshot.test.js`：原参数复用、密钥排除、旧图兼容、实际请求编译、待处理/成功/恢复记录传递。
- `npm run test:smoke`：现有扩展和服务端冒烟检查。
- `node tests/novelai/module-closure.test.mjs`：浏览器模块依赖检查。

实际 SillyTavern 页面尚未验收：更新扩展后生成一张图，切换预设和尺寸，打开小铅笔确认记录，修改场景、角色 TAG 并重绘；同时检查刷新后的记录。没有执行真实大模型或付费生图调用。使用整条后台 Draw Run 时，还需同步更新服务端插件并重启，使后台交付也带上原文；普通浏览器解析流程的本次改动无需更新服务端。
