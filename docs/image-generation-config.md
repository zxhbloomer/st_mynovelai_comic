# 花漫画：图片生成配置记录

每张新生成的图片保存生成时的预设名称、预设 ID、提示词前缀及生图参数。尺寸和种子取自实际发送的请求，包括悬浮窗尺寸覆盖和随机种子解析后的值。

点击小铅笔，在提示词上方查看生成配置。保存修改后的场景、角色提示词，再使用原有重绘按钮，会沿用这张图的参数和前缀。切换当前预设、修改原预设或改变悬浮窗尺寸，不会替换已有图片的记录。重绘沿用实际种子，因此随机种子预设生成的图片也使用原图种子。

记录覆盖聊天手动/自动配图、文本配图、失败记录和后台任务交付日志；画廊导出保留记录。配置存在本地图片缓存中，删除图片或清理缓存后不能从图片文件恢复这些记录。

不记录 API 密钥、地址或连接设置。重绘的地址、发送模式、超时和密钥读取当前配置。

## 原始描述与重新解析 TAG

新图还保存场景解析前的原始正文。点击小铅笔后，编辑“原始描述（供大模型解析）”，点击“重新解析 TAG”。使用花漫画现有大模型解析设置、提示词预设、角色库和世界书，重新生成当前一张图的场景及角色 TAG。它不修改聊天正文，也不为整层聊天追加多张图片。

解析成功后可继续微调场景和角色 TAG，再点击“保存并生图”（失败占位使用“保存并重试”）。重绘使用图片记录的生图参数。也可只“保存 TAG”，稍后再重绘。修改原始描述但尚未成功解析时，保存会提示先解析；解析失败保留之前的 TAG。取消编辑或关闭扩展会中止未完成的解析。

这里保存的是解析前的正文，不是完整的大模型请求，系统规则、世界书、角色资料和大模型连接配置仍读取当前设置。原文可能是整层正文，多张图可以共享同一份原文；编辑单张图时解析数量固定为一张。

旧图未保存原文时读取当前楼层正文，并明确标注来源，不能恢复生成时已经丢失的正文。保存后保留这一来源标注；成功重新解析后，记录本次编辑过的输入。

旧图没有这些记录，编辑区会提示“旧图未记录生成配置，重绘使用当前预设和尺寸”，不会推测原配置。
