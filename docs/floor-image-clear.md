# 清空本楼层图片

入口仅在楼层“花漫画”的下拉菜单，名称为“清空本楼层图片”。右下角悬浮菜单没有这个入口。

点击后逐个调用已有图片移除操作，移除本楼层当前显示版本的花漫画图片标记、失败占位、各图片位置的历史缓存和选择记录，并保存聊天。正文保留，不操作其他楼层、其他聊天或本楼层其他 swipe 版本。已经保存到服务器的图片文件不进行磁盘删除。

生成任务尚未完成时提示先中止或等待完成，避免清空后新图片再次插入。清理中切换聊天或当前消息版本会停止继续清理；操作失败时可能已清除部分图片，可回到本楼层再次点击完成剩余清理。

验证：`node --test tests/novelai/floor-image-clear.test.mjs` 覆盖当前楼层范围、重复标记、空楼层、切换聊天/版本后的停止；现有冒烟、模块依赖和语法检查通过。尚未在实际 SillyTavern 页面操作验收。
